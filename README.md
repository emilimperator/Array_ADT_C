# Array ADT in C

This project implements an Array Abstract Data Type (ADT) in C using dynamic memory allocation.

## Features
- Append / Insert / Delete
- Insert into sorted array
- Reverse / Left Rotate / Right Rotate
- Linear Search / Binary Search
- Max / Min / Sum / Average
- Merge two sorted arrays

## How to run
Compile:
- `gcc Array_ADT.c -o array_adt`

Run:
- `./array_adt`
